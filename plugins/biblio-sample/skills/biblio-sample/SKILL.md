# biblio-sample

これは外部本棚 `biblio-shelf` から「仕入れ」られることを確かめるための最小の biblio (skill) である。司書がこの skill を marketplace 経由で install するか、リポを clone して収蔵したとき、本ファイル (`SKILL.md`) がツリーに存在し、`plugin details` で発火可能な形で列挙されれば仕入れ成功とみなす。発火されたら「biblio-sample を外部本棚から仕入れました」と一言報告するだけでよい。
